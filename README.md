# Biuro podróży

Prosta strona internetowa biura podróży prezentująca oferty wycieczek.
## Technologie

HTML, CSS, JSON

## Uruchomienie

```bash
git clone https://github.com/KAja278/projekt_TI.git
cd projekt_TI
```

Otwórz `index.html` w przeglądarce.

## Funkcje

* lista ofert wycieczek
* dane z JSON
* responsywny layout
